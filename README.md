**Backend:** Python, Django, Django REST Framework, Flask
**Dados:** PostgreSQL, Supabase, SQLite
**Interface:** Flet (desktop e Android), React, TailwindCSS
**IA:** Integração de LLMs (Claude, Gemini, Groq) em aplicações, com extração de dados de PDF e chat
